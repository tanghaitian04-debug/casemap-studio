# CaseMap Studio

案件地图动画工作台。使用地球定位、俯视地图、人物和车辆轨迹、字幕及影视示意特效，把已核实的事件整理成可以在手机上编辑的动画项目。内置松湾市停车场追逐是 30 秒虚构演示。

- [在线编辑器](https://tanghaitian04-debug.github.io/casemap-studio/)
- [GitHub Actions 视频渲染](https://github.com/tanghaitian04-debug/casemap-studio/actions/workflows/render.yml)
- [松湾市示例项目](examples/demo.json)
- [地图与地球纹理署名](assets/NOTICE.md)

## iPhone 操作指南

1. **打开编辑器。** 使用 Safari 访问在线编辑器。底部的「预览」「项目与对象」「属性编辑」可切换工作区。
2. **创建项目。** 顶部点「新建」，或在「项目与对象」恢复演示项目。在「属性编辑」粘贴经过，点「生成示意动画」得到可编辑的脚本。生成前可先导出当前项目。
3. **导入地图。** 在「项目与对象」上传有使用权的 PNG/JPG 底图并填写原始署名。展开「地球定位与视频设置」调整地点名、经纬度和成片格式。地球定位经纬度控制开场镜头，底图的放置和校准由你完成。
4. **制作路径。** 添加人物或车辆，返回「预览」，把播放头移到所需时间并点地图。拖动现有圆点修正位置。在「属性编辑」可以调整关键帧时间、缓动与显示区间。路径速度由相邻点的时差和距离决定。
5. **添加镜头。** 把播放头移到目标时间，调整中心、缩放、旋转、倾斜角及缓动，再点「在当前时间添加镜头」。选择跟随对象可让镜头从该关键帧起跟随，直至下一个镜头关键帧改变设置。
6. **添加特效、字幕和声音。** 在属性中选择轨道类型并添加，展开新增条目编辑时间和参数。素材会嵌入项目文件。音频建议使用短小的 MP3 或 WAV。
7. **保存项目。** 点「保存 JSON」把项目下载到 iPhone 的「文件」App。本机自动保存受 Safari 存储额度限制，导出的 JSON 可跨设备重新导入。内置示例地图和地球纹理随编辑器提供。
8. **导出 MP4。** 点「导出视频」，设置文件名并下载渲染 JSON。将项目上传到你有读写权限的分支，如 `examples/my-scene.json`。前往「Actions → Render CaseMap MP4 → Run workflow」，选择该分支、填写项目相对路径，等待完成后点运行详情下的 `casemap-mp4`。在「文件」App 解压下载文件，再把 MP4 导入剪映或 Premiere。

公开仓库的分支和提交历史对外可见。请把含敏感或未公开素材的 JSON 留在私人环境，或交给你授权的 Codex 会话渲染。GitHub Pages 只承担编辑和预览。正式成片通过 Actions 的手动工作流触发。

## 格式与功能

| 模块 | 功能 |
| --- | --- |
| 地球 | Canvas 实时计算透视球面，自转并推近经纬度，再推进至可换底图 |
| 地图 | 原创虚构俯视图，支持导入卫星截图并保留署名 |
| 人物和车辆 | 自定义图标、颜色、朝向、尺寸、层级、出现区间、路径关键帧与缓动。警车灯自动闪烁 |
| 镜头 | X/Y、缩放、旋转、倾斜、跟拍目标与缓动 |
| 特效 | 示意闪光、警示标记、定位圈、发光、高亮、警灯、文字、暗角、推近与震动 |
| 时间轴 | 地球、镜头、地图、人物、车辆、特效、字幕与音效。定位、逐帧、缩放、全屏预览 |
| 案件描述 | 关键词规则匹配生成可修改的项目。生成的时间及移动路线均为示意 |
| 导出 | 720p/1080p、默认 30fps、16:9 H.264 MP4，可混合项目音效、验证帧数并生成 ffprobe 报告 |

项目格式为 `version: 1`，地图左上角为 `0,0`、右下角为 `1,1`。时间单位为秒。录入实际案例时，使用已核实信息并保留画面上的示意标识及素材来源。

## 云端开发与验收

`npm ci` 安装依赖，`npm test` 执行 JSON、插值、路径、镜头及草稿恢复测试，`npm run build` 生成静态发布目录。CI 还会在 Chromium 和 WebKit（iPhone 13 尺寸）中检查项目编辑、回读及布局，并通过 FFmpeg、ffprobe 检验两种分辨率的短片。

逐帧导出由 Playwright 加载相同的 JavaScript 画布引擎，按帧号求时间，再将图像序列交给 FFmpeg。容器无法启动浏览器时可用 `--native`，它以相同 JavaScript 在 Node Canvas 绘制。字体和图形栅格化细节可能随环境变化。原有 `render.py` 作为旧版素材的兼容入口保留。

## 当前限制与 V1.1

旋转地球和地面以示意地图过渡。V1.1 优先接入有明确再利用授权的地理服务和地图配准，增加持续的地形俯冲、对象相对约束、音轨波形与剪辑、镜头高度和私人渲染队列。当前浏览器提供规则生成，外部 AI 接入需由服务端保管密钥。实机 Safari 与 Actions 的运行结果以实际验收为准。
